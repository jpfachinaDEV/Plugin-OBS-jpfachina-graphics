# JP Fachina Graphics 1.0.3 beta

Pré-lançamento para Windows x64 com OBS Studio 33.0.1 e Qt 6.11.1.

- ABA 3 com cinco scoreboards e controles integrados de partida.
- Editor de posição com prévia do scoreboard, arraste, alças, alinhamento, tamanho e aplicação ao vivo.
- Take/Out e atualização de pontuação e cronômetro usando a composição nativa do OBS.
- Posição individual preservada na troca de modelos e entre sessões do evento.

Instale com o OBS fechado. Use **Link OBS** para associar a composição à cena. Confira o [resumo dos testes](TESTES-1.0.3-beta.md) antes de usar em transmissão ao vivo.
