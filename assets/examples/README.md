# Exemplos da galeria

`qr-example.png` é um QR-Code real para https://example.org, um domínio de exemplo.
Foi gerado com node-qrcode 1.5.4 apenas como material demonstrativo.

As outras artes da galeria são geradas por QPainter em `tools/gallery.cpp`.
A marca original permanece intacta em `assets/branding`. O clipe colorido usado
na demonstração é um fixture próprio de teste, em `tests/fixtures/sample.mp4`.
Nenhuma mídia de uma biblioteca pessoal é necessária para reproduzir as capturas.
