# Contribuir

Abra uma issue descrevendo o comportamento, a versão do plugin, do OBS e do Qt,
o Windows e os passos para reproduzir. Use mídia demonstrativa sempre que possível.
Ao anexar logs, remova senhas, tokens, URLs privadas e informações pessoais.

Para alterações, consulte `docs/BUILD.md`. Preserve o contrato de seleção/preparação
separado de publicação, confirmação real de tally e isolamento entre categorias
ou projetos. Movimentos do editor não devem enviar comandos ao OBS.

Execute os testes pertinentes à alteração e descreva a validação no pull request.
A marca original tem direitos próprios; consulte a proveniência em `assets/branding`.
