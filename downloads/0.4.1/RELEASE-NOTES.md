# JPFachina OBS Controller 0.4.1

Plugin nativo para OBS Studio 33.0.1 / Qt 6.11.1 / Windows x64.

- Duas abas com miniaturas 16:9 e Take/Out independentes por categoria.
- Seleção verde e confirmação real de programa em vermelho.
- Editor local por categoria, setas grandes e incrementos 1/10/50 pixels.
- Projetos/eventos independentes em Cenas; associações reais em Link OBS.
- Integração nativa ou WebSocket 5 autenticado, reconexão e vídeos em loop.
- Corrige a dependência Qt WebSockets para o kit usado pelo OBS 33.0.1.

Feche o OBS antes de instalar. Use o EXE para instalação normal e o ZIP para
instalação manual/portátil. Não use o pacote antigo Qt 6.8.3 no OBS 33.
A biblioteca existente é preservada. Consulte o manual e os limites de validação.

Os hashes SHA-256 estão em SHA256SUMS.txt. As capturas usam dados demonstrativos
e uma conexão real com OBS isolado. Código GPL-2.0-or-later, com avisos de terceiros.
